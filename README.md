# AI Lead Management & Follow-Up Automation

An AI-powered lead management and follow-up automation project built using **n8n** as part of the Digital Egypt Pioneers Initiative (DEPI) – AI Automation Track.

## Project Overview

This project automates the lead management process by collecting customer information, analyzing leads using AI, assigning lead scores and priorities, and supporting automated follow-up communication.

The goal is to reduce manual work, improve lead organization, and help businesses manage potential customers more efficiently.

## Key Features

- Lead Data Collection
- AI-Powered Lead Analysis
- Lead Scoring and Prioritization
- Automated Email Notifications
- Telegram Notifications
- Lead Status Management
- Error Handling and Alerts

## Technologies & Tools

- n8n
- AI Agents
- Google Sheets / Data Tables
- Google Gemini
- Gmail
- Telegram
- Webhooks
- JSON

## Workflow Overview

1. Receive lead information through a webhook.
2. Store lead data in the lead management system.
3. Analyze the lead using AI.
4. Assign a lead score and priority.
5. Send automated notifications.
6. Handle workflow errors and send alerts.

## Example Lead Data

The workflow manages information such as:

- Name
- Email
- Company
- Service
- Budget
- Message
- Lead Score
- Priority
- Status

## How to Use

1. Download the exported n8n workflow JSON file.
2. Open your n8n instance.
3. Import the workflow.
4. Configure your own credentials and API keys.
5. Connect the required services.
6. Test the workflow before activation.

## Security

Never upload API keys, passwords, OAuth tokens, or private credentials to GitHub.

Use your own credentials when importing and configuring the workflow.
